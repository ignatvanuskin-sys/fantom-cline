# Fantom — сайт квест-рума (Усть-Каменогорск)

Тёмный кинематографичный одностраничник с онлайн-записью и мгновенными
уведомлениями в Telegram.

**Стек:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4

---

## Быстрый старт

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
npm run start   # запуск production-сборки
```

## 2. Фотографии

Сейчас обложки и галереи — CSS-градиенты, чтобы макет был полностью рабочим
без единого файла. Как заменить:

1. Положите фото в `public/photos/` (например, `public/photos/sanatorium-1.jpg`).
2. Обновите `gallery` в `src/data/quests.ts`.
3. В `QuestCard.tsx` замените блок обложки на:

```tsx
<Image
  src={quest.gallery[0]}
  alt={`${quest.name} — общий вид комнаты`}
  fill
  sizes="(max-width: 640px) 78vw, (max-width: 1024px) 50vw, 33vw"
  className="object-cover"
  // тёмная цветокоррекция
  style={{ filter: "brightness(0.7) contrast(1.15) saturate(0.85)" }}
/>
```

4. Аналогично в `QuestModal.tsx` для галереи — через `next/image`
   (оптимизация + ленивая загрузка).

**По съёмке:** тёмная цветокоррекция, лёгкий boost contrast.
Держите вес до ~200 КБ на мобильную версию (AVIF/WebP).

### Hero-фон

В `Hero.tsx` найдите блок с `radial-gradient` и замените на фото или видео.
Для видео обязательно постер — иначе медленный интернет увидит чёрный экран:

```tsx
<video autoPlay muted loop playsInline poster="/hero-poster.jpg"
       className="absolute inset-0 h-full w-full object-cover">
  <source src="/hero.mp4" type="video/mp4" />
</video>
```

### OG-изображение

Положите картинку 1200×630 в `public/og.jpg` — превью при пересылке
ссылки в мессенджерах.

## 3. Настройка Telegram-бота

Форма → `POST /api/booking` → `sendMessage` вам в чат.

### Шаг 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. `/newbot` → задайте имя и username (например, `fantom_uka_bot`).
3. Скопируйте **токен**.

### Шаг 2. Узнайте `chat_id`

Добавьте бота в группу (или напишите ему в личку), затем откройте:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Найдите `"chat":{"id": -1001234567890}` (группа) или положительный id (личное сообщение).

### Шаг 3. Задайте переменные окружения

Создайте `.env.local` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_CHAT_ID=-1001234567890
```

### Шаг 4. Проверьте

```bash
npm run dev
```

Отправьте тестовую заявку через форму — она придёт в Telegram за секунду.

> **Без настроенного бота форма всё равно работает** (ответ 200, заявка пишется
> в лог сервера) — чтобы демо можно было показывать клиенту до подключения.

> **При деплое на Vercel** задайте те же переменные в
> Dashboard → Project → Settings → Environment Variables, затем передеплойте.

## 5. Дизайн-система

Все токены — в `src/app/globals.css` внутри блока `@theme`:

| Токен | Значение | Назначение |
|---|---|---|
| `--color-void` | `#0a0a0a` | основной фон |
| `--color-ash` | `#0d0d0d` | фон чередующихся секций |
| `--color-smoke` | `#141414` | карточки, панели |
| `--color-blood-700` | `#8a0303` | основной красный акцент |
| `--color-blood-500` | `#b8121a` | hover, подсветка |
| `--font-display` | Creepster | тревожные заголовки |
| `--font-sans` | Inter | основной текст |

**Правила темы:**
- фон никогда не чисто-чёрный — только `#0a0a0a`/`#0d0d0d`;
- красный — точечно (кнопки, hover, индикаторы), **не заливками**;
- текст не чисто белый, а `#c9c9c9` — белый на чёрном в хорроре выглядит дёшево;
- display-шрифт — только для заголовков, для текста — Inter.

Сменить акцентный цвет (например, на ржавый) достаточно в одном месте:
поменяйте `--color-blood-*`.

## 6. Карта: почему своя, а не 2ГИС в iframe

**2ГИС запрещает встраивание.** Их страницы отдают заголовок
`Content-Security-Policy: frame-ancestors 'none'` — в iframe будет пустота.
Официальный виджет требует платный ключ API. Яндекс.Карты тоже убраны:
для цокольного этажа поиск по строке адреса попадал во вход в ТЦ, а не
в нужную точку.

Поэтому карта своя: **Leaflet + тайлы OpenStreetMap**, метка — по точным
координатам входа из ссылки 2ГИС (82.595183, 49.968637), zoom 17.
Тайлы приглушены фильтрами, метка — пульсирующее кровавое кольцо.

**2ГИС при этом не потерян** — он остаётся источником данных и целью для
кнопок «Открыть в 2ГИС» (карта, блок контактов). Это ровно то, что нужно
гостю: быстрый маршрут в его любимом приложении.

Файлы: `src/components/DarkMap.tsx`, координаты — `BUSINESS.geo` в
`src/data/quests.ts`.

> Leaflet грузится **динамическим импортом** — он обращается к `window`
> уже на этапе импорта модуля, и статический импорт роняет пререндер
> Next.js с «window is not defined». Динамика заодно выносит ~51 КБ
> в отдельный чанк, который не грузится вместе с основным бандлом.

## 7. WebGL-дым (ShaderBackground)

`src/components/ui/gem-smoke-diamond.tsx` — один WebGL-канвас без
зависимостей. Оригинал: Paper Shaders «Gem Smoke» (Apache-2.0).

**Палитра перекрашена под проект** (в оригинале был самоцветный градиент):
уголь `#0a0a0a` → кровавый `#8a0303` → ржавый `#6b4a24` → светлая кровь.
Плюс приглушена насыщенность (0.82) и усилена виньетка (0.55) — иначе
дым выглядел бы «пластиково» и не вписывался в хоррор-тему.

Почему подходит под требование «мрак»:
- время замедлено (`timeScale 0.55`) — дым клубится, а не мельтешит;
- `prefers-reduced-motion` → рисуется **один статичный кадр**;
- вне экрана рендер полностью останавливается (IntersectionObserver);
- при `visibilitychange` на скрытой вкладке рендер тоже стопорится;
- DPR ≤ 2 и потолок ~2 млн пикселей — не греет GPU на 4K;
- если WebGL недоступен — тихий откат на CSS-фон родителя.

Хотите темнее — крутите `UNIFORMS.vignette` (0.55) и `brightness` (-0.02).
Хотите быстрее — поднимайте `timeScale`.

## 8. Мрачные эффекты и анимации

- Все анимации — только `transform` / `opacity` (без layout-свойств).
- Появление секций — через `Reveal` («раскрытие из темноты»).
- Скример-толчок в секции квестов — **один раз**, отключается при
  `prefers-reduced-motion`.
- Кровавый след за курсором — только на устройствах с мышью.
- При `prefers-reduced-motion: reduce` глобально отключаются flicker, drift и
  тряска — остаются мягкие fade.
